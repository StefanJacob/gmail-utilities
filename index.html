Gmail Utilities

Personal tools by Stefan Jacob

This site describes a small set of personal utilities that use Google APIs to help Stefan Jacob manage his own Google account. They are not offered to the public and are used only by their owner.

Utilities

  • Gmail inventory — a script that reads message headers (sender, date, labels, read/unread status, list and unsubscribe headers) and the list of Gmail filters, with read-only access, to help clean up and organise the owner's inbox.
  • Drive backup (rclone) — a backup tool that copies files between the owner's computer and his own Google Drive.

See the Privacy Policy for how Google user data is handled.
